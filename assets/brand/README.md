# Presto AI Dash — Watchful Meter icon

Approved product tagline: **Always in view. Never in your way.**

These supplied masters are the repository's canonical artwork. See
[the branding guide](../../docs/branding.md) for messaging, device constraints
and the derived-asset generation command. The web copies and `presto/brand.py`
are generated from this bundle, not edited independently.

This bundle contains a vector reconstruction of the selected original **Watchful Meter** concept. It deliberately preserves the friendly display face with quota-meter eyes and cyan smile. No AI sparkle, lettering, device pedestal, or other new visual feature has been added.

## Files

- `presto-ai-dash-icon.svg` — primary scalable, transparent-background color mark.
- `presto-ai-dash-icon-mono-dark.svg` — dark neutral single-hue variant for light surroundings.
- `presto-ai-dash-icon-mono-light.svg` — reversed neutral variant for dark surroundings.
- `png/presto-ai-dash-{16,32,64,128,256,512,1024}.png` — transparent PNG exports.
- `presto-ai-dash-favicon.ico` — multi-size favicon (16, 32, 64, 128, 256px).
- `previews/icon-size-and-theme-check.png` — scale and light/dark visual check.

## Usage

- Use the color SVG as the master source; export to larger PNG sizes when needed.
- Use the 256 or 512px PNG for most README, promotional, and web assets; 64px for small UI.
- 16px is a compact fallback only; the logo is strongest from 32px upward.
- The mark is intentionally independent of the physical Presto hardware, so it can also identify the project on other desk displays.

## Validation (2026-10-30)

- Master SVG successfully rendered at all seven requested sizes using Inkscape.
- Every PNG has the correct dimensions, RGBA color, and a genuinely transparent outer canvas.
- The ICO contains all five listed icon sizes.
- Visual comparison at native 16, 32, 64, and 128px on white and GitHub-like dark backgrounds passed. At 16px the face is a tiny recognizable colored mark; the individual gauge arcs read more clearly at 32px and above.
