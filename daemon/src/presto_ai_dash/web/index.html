Sound is off until you turn it on here: a desk device must not beep unannounced. Tick this box to let the Presto chirp. One chirp for a warning, two for a critical or rate-limited service. A warning that persists does not chirp again, and a recovery is silent. Long-pressing the Presto mutes the sound for a few hours; the screen shows how long is left.

How long the Presto stays muted after a long press, from 0 to 48 hours. Zero means it stays muted until you long-press again. The screen shows a MUTED chip with the time left, so a mute cannot be forgotten. A restart clears the mute.

Browser sessions Applies to every browser

A browser stays signed in for seven days. If someone else may have signed in with your admin token, sign every browser out, then lock this page and sign in again. A token you set in the configuration file also ends the sessions made under the old one when you change it; a token the daemon generates at each start does not, so this is the way to end those.

About and help Applies to all services

Cloud and subscription sources

Available subscription connectors show current allowance meters in your source list. OpenCode Go reports quota percentages. Ollama Cloud reports dated activity; monthly included and purchased credits are read separately from rolling activity. Codex uses your existing ChatGPT login in the local Codex app. Claude uses a Claude Code terminal quota export. Subscription allowances are separate from API billing.

The Fake demo source

Order

The order of the accounts on the Services tab is the order of the Presto Home list and of the swipe cards. It saves automatically and applies on the next poll.

Logs and diagnostics

The daemon writes its own log to the console it was started from (python -m presto_ai_dash.app --config dash.toml --admin). The Problems list on the Status tab shows the recent warnings and errors without reading the log file. The device prints its fetch diagnostics to the Presto's serial console.
